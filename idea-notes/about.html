이 사이트 소개

아이디어를 잊지 않고, 바로 AI에게 맡길 수 있는 형태로 정리해 두는 곳입니다.

만든 목적

떠오른 프로젝트 아이디어는 메모장, 메신저, 수첩에 흩어져 금방 잊힙니다. 이 사이트는 아이디어마다 페이지 하나를 만들고, 만들 이유·기능·기술·AI에게 줄 첫 프롬프트까지 같은 형식으로 정리해 둡니다. 나중에 아이디어를 꺼내 쓸 때 프롬프트를 그대로 복사해 바로 바이브코딩을 시작할 수 있습니다.

새 아이디어를 추가하는 방법

  1. 템플릿 복사 — template.html 파일을 복사해서 ideas 폴더에 붙여 넣습니다.
  2. 이름 변경 — 다음 번호로 이름을 바꿉니다. 예: idea-04.html
  3. 경로 수정 — ideas 폴더 안으로 옮겼으므로, 파일 안의 링크 앞에 ../ 를 붙입니다. (템플릿 상단 주석에 고칠 곳이 적혀 있습니다.)
  4. 내용 작성 — 회색 안내 문구를 지우고 실제 내용을 적습니다. 다 쓰면 class="placeholder" 는 지워도 됩니다.
  5. 목록에 카드 추가 — index.html 에서 <article class="idea-card"> 하나를 복사해 붙이고 제목·요약·배지·링크를 바꿉니다.
  6. 이전/다음 링크 연결 — 바로 앞 아이디어 페이지의 "다음 아이디어 없음"을 새 페이지 링크로 바꿉니다.

배지 클래스 정리

  • 구상 중 → status-idea
  • 개발 중 → status-dev
  • 완성 → status-done
  • 난이도는 level-badge 안의 글자만 쉬움 / 보통 / 어려움으로 바꿉니다.

색 바꾸기

모든 색은 css/style.css 맨 위 :root 에 모여 있습니다. 여기 값만 바꾸면 사이트 전체 색이 함께 바뀝니다.

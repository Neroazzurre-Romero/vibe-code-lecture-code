② 데이터 자동 분석

작성일: 2026-11-20
보통 구상 중

한 줄 요약

쌓인 데이터로 수율·불량 유형·추세를 자동 계산하고, 기준을 벗어나면 즉시 알람을 띄우는 분석 엔진

만들게 된 이유

데이터가 모여도 수율 계산, 불량 유형 집계, 추세 비교를 매번 엑셀로 손으로 하면 문제가 생긴 뒤에야 알게 된다. 수집된 데이터를 정해진 규칙으로 자동 분석해서, 수율이 떨어지거나 특정 불량이 늘어나는 순간을 바로 잡아내고 원인 후보까지 보여 주고 싶다.

주요 기능

  • 수율 자동 계산: 일·교대·모델·라인별 투입/양품/불량, 양품율
  • SBL Alarm: 양품율 85.0% 이하 구간 자동 표시 및 알림
  • 불량 파레토: 불량 코드별 건수·비율 순위, 상위 불량 TOP 5
  • 추세 분석: 시간대별 수율 그래프, 전일·전주 대비 증감
  • SPC 관리도: 관리 한계선(UCL/LCL) 이탈 및 연속 하락 패턴 감지
  • 비전 분류 결과 통계: YOLOv8 분류 결과의 클래스별 분포·신뢰도 추이
  • 분석 결과를 DB에 저장해 ③ 보고서에서 그대로 사용

대상 사용자

수율과 불량을 실시간으로 챙겨야 하는 공정·품질 엔지니어, 라인 관리자

사용할 기술 / AI 도구

  • Python
  • pandas
  • NumPy
  • SQLite
  • Streamlit
  • Plotly
  • YOLOv8 결과 연동
  • Claude

AI에게 줄 첫 프롬프트 초안

Python + Streamlit으로 생산 데이터 자동 분석 대시보드를 만들어줘.

[입력]
- SQLite 테이블 production
  (timestamp, line, model, shift, input, ok, ng, defect_code)

[분석]
1. 날짜 / 교대 / 모델별 투입·양품·불량 합계와 양품율(소수점 1자리)
2. 양품율 85.0% 이하 행은 빨간색 강조 + 상단에 SBL Alarm 배너
3. 불량 코드별 파레토 차트 (막대 + 누적 비율 선)
4. 시간대별 양품율 추이 선 그래프, 전일 대비 증감 표시
5. 양품율 SPC 관리도 (평균 ± 3σ), 한계선 이탈 지점 표시

[화면]
- 좌측 사이드바: 기간, 라인, 모델 필터
- 상단 KPI 카드 4개: 총 투입, 양품, 불량, 양품율
- 화이트 배경 + 네이비(#000080) 테마, 밝은 파란색 사용 금지
- 60초마다 자동 새로고침

분석 함수는 화면 코드와 분리(analysis.py)하고,
즉시 실행 가능한 전체 완성 코드로 줘.

메모
